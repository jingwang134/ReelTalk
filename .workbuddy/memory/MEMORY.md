# ReelTalk — 项目记忆

## 产品
- **名称**：ReelTalk（reel 电影胶片 + talk，押头韵，点题"从影视/综艺/访谈学口语"）
- **文件**：`ielts-speak-lab.html`（单页应用，LocalStorage 持久化）
- **定位**：雅思口语工作台，三个维度：话题练习 / 地道表达 / 阅读跟练
- **当前版本**：v4（三维度实用重构）

## 三个维度
1. **话题卡片** — 24 个雅思话题 × 3-4 道真题，选风格 → 生成答案 → 跟读练习
2. **地道表达** — 8 大场景分类 45+ 条表达卡片，闪卡复习 + 收藏导出
3. **阅读跟练** — 15 张摩登家庭金句卡片，聆听 + 逐词跟读

## 核心机制（保留）
- 语料分析引擎：词频 / N-gram / 句首模式 / 话语标记 / 句式 / 正式度 / 语气基调 / 签名表达
- 风格 DNA 聚合 + 风格迁移生成（7 步变换）
- 轻量游戏化：XP / 连续打卡
- MF 预计算分析数据（__MF_ANALYSIS__，100万词）嵌入 HTML

## 用户偏好

- v3 "好看但不实用" → v4 去掉多邻国式路径/心心系统，改为三维度直接实用
