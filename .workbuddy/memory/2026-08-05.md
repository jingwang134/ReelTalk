## IELTS Speak Lab v2 — 风格学习型口语工作台（重构版）

用户反馈初版"太low"——初版硬编码了三个固定风格模板，没有真正从语料中学习。

v2 完全重构为**风格学习系统**，核心理念："你喂什么，它学什么，生成什么"。

### 架构变化
- **语料分析引擎 (CorpusAnalyzer)**：每条语料提交时自动分析：
  - 词频统计（去除停用词后的top 20高频词）
  - N-gram提取（bigram/trigram高频短语）
  - 句首模式（sentence openers，每个句子的前3个词）
  - 话语标记检测（discourse markers: you know, honestly, literally, I'm not gonna lie 等）
  - 句式统计（平均句长、最长/最短句、总词数/句数）
  - 正式度评分（基于缩略词频率和复杂词率，1-10分）
  - 语气基调检测（enthusiastic/self_deprecating/sarcastic/warm/dramatic/deadpan）
  - 感叹号频率、问句频率
  - 签名表达（signature expressions = 高频 trigram）

- **风格档案 (StyleProfile)**：用户自建、自命名。聚合档案下所有语料的分析结果，形成 composite style DNA。

- **风格迁移引擎 (StyleTransferEngine)**：基于风格DNA对基础答案做7步变换：
  1. 话语标记注入（按DNA频率随机插入discourse markers）
  2. 词汇替换（将通用词替换为DNA高频词）
  3. 签名表达植入
  4. 句式结构调整（按avgSentLen拆分/合并句子）
  5. 语气调整（按primaryTone替换程度副词）
  6. 正式度匹配（展开/缩合 contraction）
  7. 感叹号调整

### 预置数据
首次启动自动创建三个风格档案和对应语料（摩登家庭/卡戴珊/Jimmy O Yang），但系统完全开放——用户可以创建任意风格、投喂任意语料。

## v3 — 多邻国式游戏化重构

### 多邻国式设计语言
- **顶部状态栏**：XP积分、连续打卡火焰🔥、每日目标进度环（SVG圆环）
- **学习路径**：垂直zigzag路径节点，按Part 1/2/3分组，每个话题是一个圆形按钮节点
  - 节点状态：locked（灰色锁）/ available（弹跳动画）/ completed（显示星星⭐⭐⭐）
  - 点击节点开启练习会话
- **风格选择**：路径上方横向chip选择器，可切换风格档案
- **分步练习会话**（全屏overlay）：
  1. READ — 阅读答案，点击高亮表达预收藏
  2. LISTEN — 听力训练，可调速度（慢/正常/快），大圆形播放按钮
  3. SPEAK — 逐句跟读，麦克风录音 + 语音识别打分 + 即时反馈（绿/黄/红）
  4. COLLECT — 确认收藏表达（chip点击切换）
  5. COMPLETE — 完成画面：星星、发音匹配度、XP奖励、收藏数
- **游戏化系统**：
  - XP：练习完成+10、每星+5、每个收藏表达+2、每日目标+20、复习+5
  - 连续打卡：跨天检测streak，3天/7天成就弹窗
  - 每日目标：默认3个练习，完成时进度环填满+成就弹窗
  - 心心系统：跟读失败扣心，3颗用完跳到收藏步
  - 星星评级：发音匹配≥80%=3星，≥50%=2星，其余1星
- **三个标签页**：
  - 🏠 学习路径（Home）
  - 🧪 语料实验室（Lab）— 语料投喂+分析+风格档案管理
  - 📚 表达记忆库（Bank）— 闪卡复习模式 + 导出
- **视觉风格**：多邻国配色（绿#58cc02/蓝#1cb0f6/红#ff4b4b/金#ffc800），圆角16px，按钮带3D阴影（bottom border模拟物理按键），弹跳动画

## v4 — 三维度实用重构

用户反馈 v3 "好看但不实用"——多邻国路径 + 风格实验室虽然视觉好，但实际练习体验不顺手。

### 三个独立维度
1. **🎯 话题卡片** — 左侧话题目录（Part 1/2/3 分类），右侧问题卡片 + 风格选择 + 生成按钮 + 跟读练习
   - 24个话题 × 3-4道真题（基于2024-2025雅思口语题库）
   - "换一题"按钮在同一话题下切换
   - 答案中自动高亮表达（基于风格DNA），点击即收藏
2. **💬 地道表达** — 8大场景分类，45+条表达卡片（短语 + 释义 + 例句 + 来源）
   - 场景：日常寒暄、表达观点、同意/反对、描述感受、过渡衔接、强调夸张、讲故事、结束语
   - 闪卡复习模式（正面看短语，翻面看释义+例句）
   - 搜索过滤 + 收藏导出
3. **📖 阅读跟练** — 15张摩登家庭金句/片段卡片
   - 分类：家庭金句、人生哲理、幽默一刻、温暖瞬间
   - 聆听 + 逐词跟读练习
   - 关键词自动高亮

### 设计原则
- 去掉 zigzag 路径、心心系统、多步会话 overlay 等游戏化元素
- 保留 XP/streak 状态栏作为轻量激励
- 核心交互极简化：选话题 → 换题 → 选风格 → 生成 → 跟读
- 所有数据（话题问题库、表达库、片段库）直接嵌入 HTML，无加载延迟

### 技术
- 保留 NLP 引擎（analyzeCorpus/getDNA）和风格迁移（generateAnswer）
- MF 预计算分析数据（__MF_ANALYSIS__）继续使用
- 代码量从 ~2100 行精简到 ~1000 行

## v4.1 — 答案引擎重写

用户发现两个致命问题：
1. 生成的答案和题目完全对不上（问hometown答"being open to new experiences"）
2. 摩登家庭风格没有体现（只是撒了you know/honestly，核心句式是6句万能废话）

### 根因
`buildSentences()` 硬编码6句通用模板，随机从DNA topWords抽词填入语法槽位：
- topWords = ["i'm","what","oh","don't","like"] → 填入 "sometimes you just have to ___ the flow"
- 产出：**"you have to what the flow"** / **"you're the flow"** → 乱码
- 这6句模板跟任何话题都无关

### 修复
**话题内容 + 风格表达完全分离**：

1. `TOPIC_CONTENT` — 24个话题的知识锚点库
   - 每个话题 5-8 个完整句子片段（fragment），覆盖该话题常见角度
   - 话题专属词汇表（topicWords）

2. `STYLE_PATTERNS` — 3种风格的句式模板
   - opener（开场）/ thoughtStarter（引出观点）/ transition（过渡）/ closer（收束）
   - 每种风格 4-6 个变体，风格词表（filler）
   - 摩登家庭：warm & self-deprecating ("Oh gosh", "the thing is", "you know?")
   - 卡戴珊：dramatic & bold ("Bible", "literally", "period")
   - Jimmy O Yang：self-deprecating Asian ("sad little story", "everything's fine")

3. `generateAnswer` 重写：
   - 从 TOPIC_CONTENT[topicId] 取内容锚点（回答谈什么）
   - 从 STYLE_PATTERNS[styleId] 取句式模板（怎么谈）
   - 每句都用 topic-specific fragment + style-specific opener/transition 组装
   - injectFiller() 自然织入风格词，不再是生硬替换

4. 删除：
   - `buildSentences()` — 万能废话模板
   - `capitalize()` — 不再需要
   - 问题类型分类（isDescribe/isOpinion/isWhy）— 内容由话题决定
